# M5 language workbench — 0.6.0

M5 adds a language library to the existing Windows editor. Documents pin an immutable language revision containing their orthographies, dictionary, grammar and corpus. Language changes do not rewrite historical quotations, source spellings, typography or translations.

Run `setup.bat`, then `launch.bat`. Setup installs the pinned M0–M4 runtime through `requirements/requirements-m5.txt`, checks the dependency graph, validates repository evidence and runs every regression. M5 adds no external runtime dependency. Setup retains visible errors and per-run logs under `.local/logs/`.

## Desktop workflow

Use the **Language** menu to reach the new panels without scrolling across all the typography tabs.

- **Language:** import the verified local archive or a portable package; inspect revision differences; adopt a retained revision; browse/create/edit/remove typed records; publish a dictionary, grammar book or interlinear corpus.
- **Lexicon:** search labels, historical spellings and definitions; edit ordinary fields, IPA, pronunciation, part of speech and etymology. The structured-record tab handles multiple stable sense IDs, variants, citations, examples and future audio URLs. “Find linked occurrences” follows explicit corpus analyses.
- **Grammar:** edit rules, alternative readings and morphology records. Roots, affixes, clitics, inflection, derivation and paradigm cells share stable references and explicit features. Unknown cells can remain unknown.
- **Corpus:** inspect source tokens and glosses, edit analyses, link a pair to exact document ranges, inspect stale links, jump to a valid source range and search concordances/frequencies.
- **Symbols:** select a registered symbol/form key and insert using a hash-compatible selected font. Apply an explicit transliteration profile; unknown characters are preserved. Forward traces permit exact restoration even when transliteration collapses distinctions.
- **Numbers:** format and parse exact rational values in base 12, using a versioned ASCII or Unta convention. For example, `1/7` is `0.(186A35)` in the ASCII convention. An ellipsis explicitly marks a truncated display, while the numerator and denominator remain exact.

Record edits, imports, adoption and document links use the same guarded commands as automation. They are undoable and included in recovery. Removing referenced data is rejected atomically. A record's ID stays stable when its content changes; a separate identity needs a new record.

The bottom **PNG** and **SVG proof** buttons, the File export actions, and Publish panel now suggest names such as `Vayrshemon-English-M5_2026-10-23_10-45-12_345.png`. This is local date/time with milliseconds. The user still selects the destination; files are not overwritten silently.

## Archive evidence

“Import verified local archive” checks five original DOCX hashes before importing, and records the checked-in mapping's content hash. Original files and extracted text remain under ignored `Inputs/` and `.local/`.

| Collection | Initial import | Interpretation |
| --- | ---: | --- |
| Sources | 6 | Five DOCX files plus the existing Thimfora mapping |
| Orthographies | 1 | 47 letter symbols and 12 digits; unresolved slots remain listed |
| Input layouts | 1 | Semantic symbol/form palette, not a reconstruction of the physical keyboard |
| Transliteration profiles | 1 | Chart readings, with ambiguity and unknown-scalar preservation |
| Lexical records | 733 | Both translation charts and language terms; unfilled rows retained |
| Morphology | 7 | Hadthem tense forms; two future forms explicitly disputed |
| Grammar | 3 | Tense/aspect order, attested pronoun descriptions and construction evidence |
| Corpus | 2 | The polished source/English pairs, original transliteration and raw glosses |
| Number conventions | 2 | Attested Unta digit identities plus an editorial ASCII convention |

Stable archive IDs encode the source revision, table and row. The two chart versions are not merged on an English label. Four-cell conjunction rows retain their separate function descriptions as well as script and transliteration. Blank lexical forms remain uncertain records. “Attested” means present in that source, not approved as the latest language rule.

The Hadthem table and paired script/transliteration examples disagree about immediate and distant future suffixes. M5 preserves the table reading and a cited alternative; it selects neither as authoritative. The polished gloss's unusual `we(singular)` description is also preserved as written.

Historical font-family hints are retained with lexical variants. They do not establish an exact font identity or modern Unicode orthography, so those records keep `orthographyId: null`. IPA is empty when the archive does not provide verified IPA. The import does not guess phonetics, morphological segmentation or a complete pronoun paradigm.

## Revisions and data contracts

Application **0.6.0**, API **0.6.0**, native document **0.5.0**, language state/package **1.0.0**. M4 paint engine **1.1.0** and the existing recipe format are unchanged.

Each revision lists content hashes of typed records. An object store shares unchanged records between revisions instead of duplicating the full dictionary. Revision metadata includes stable ID, parent ID, label, UTC creation time and collection hash. Adopting an earlier revision and editing it creates a branch with that revision as parent. Native files retain the graph; portable JSON exports the selected dataset and citations. Imports make a new local revision and retain the previous one.

Schemas:

- `schemas/language-document.schema.json`
- `schemas/language-package.schema.json`
- `schemas/language-command.schema.json`
- `data/language-mcp-tools.json` and `data/language-capabilities.json`

Regenerate with `python -m tools.generate_m5_contracts`. Earlier milestone schemas stay frozen.

M1–M4 documents migrate on open and must save to a new path. The original document is retained. New M5 files require the M5 reader; `launch.bat --m4`, `--m3`, `--m2` and the lab command retain earlier interfaces.

Corpus token offsets are Unicode scalar offsets into the stored corpus text. Document links use the editor's UTF-16 offsets and grapheme boundaries. Each link records both quoted ranges, frame hashes, the corpus ID, language revision and any explicit spelling adaptation. Editing either frame marks the link stale conservatively, even if the edit was outside the range. Deleting a frame reports a missing frame. M5 does not silently re-anchor or re-gloss changed text. Links pinned to older revisions remain inspectable.

## API and MCP

All **85 operations** use the shared writer, with document identity, revision guards, idempotency and structured trace logs. New language operations include:

| Operations | Purpose |
| --- | --- |
| `language.read`, `language.revisions`, `language.diff`, `language.adopt` | Inspect and pin immutable data |
| `language.record.put`, `language.record.delete` | Typed record changes with reference checks |
| `language.archive.import`, `language.import`, `language.export` | Verified local import and portable interchange |
| `language.publish` | Printable, searchable dictionary/grammar/corpus HTML |
| `lexicon.search` | Literal lexical lookup |
| `orthography.input`, `orthography.transliterate` | Font-checked insertion and explicit mapping |
| `corpus.search`, `corpus.link`, `corpus.links`, `corpus.unlink` | Concordances, frequencies and document associations |
| `numbers.format`, `numbers.parse` | Exact rational/base-12 interchange |

Live MCP discovers API 0.6.0 from the active session. Headless use:

```powershell
.venv\Scripts\python -m vayrshemon mcp --headless --language --no-source-fonts
.venv\Scripts\python -m vayrshemon call language.revisions
.venv\Scripts\python -m vayrshemon call numbers.format --params '{"convention_id":"base12.ascii","numerator":"1","denominator":"7"}'
```

Read `session.status` before mutations. MCP names replace dots and hyphens with underscores. `language.record.put` publishes the typed schema for each collection. UI inspection and captures remain available alongside source and layout diagnostics.

## Standard demonstration

`tools/m5_demo.py` migrates a saved standard M4 page into a separate new directory. It verifies that page contents and paint are unchanged, imports the archive, adds a cited review association for the causative conjunction, links both source/translation pairs and produces the native file, PNG/SVG/PDF proofs, language package, printable books and API transcript.

```powershell
.venv\Scripts\python -m tools.m5_demo --source "path\to\M4.vay.json" --out ".local\demos\new-m5-review"
```

The page retains exactly two independent portrait columns, blue relief on black and pale English. The original corpus retains its historical clitic slot; the link records the M4 review copy's previously evidenced U+00BE to U+2019 adaptation. No new transliteration or translation is fabricated. The lexical association is marked uncertain pending review of historical orthography.

## Validation and limits

`tests/test_m5.py` covers immutable branching/adoption, content sharing, references and atomic failures, ambiguous transliteration, scalar/UTF-16 offsets, stale links and deleted frames, exact fractions, escaped publishing, hash-checked interchange, M4 migration, source/paint preservation, guarded palette input, retry/stale commands, actual archive conflicts, native filename dialogs and forced-exit language recovery. Normal setup also runs the standard translation and all earlier font/paint/export suites. See `docs/research/m5-validation.json` for the release run and demo evidence.

M5 supplies structured authoring and inspection, not an automatic morphological parser or grammar validator. Surface-token frequency is a documented heuristic; it neither normalizes legacy text nor infers morphemes. The initial seed is a transcription/review dataset, not a canonical language release. Additional paradigms, segmentation, source-face mappings and phonetic decisions remain language-development work.

Unta digit shapes/names are evidenced. The sign, radix point and repeating-fraction delimiters are explicitly editorial; spoken positional grammar is not inferred from numeral artwork. Untraced reverse transliteration is not proof of exact original spelling; use its forward trace.

Dictionary and grammar publications are searchable HTML with print styles and revision/source hashes. They preserve raw historical slots and font-family hints rather than falsely presenting them as verified Unicode. They do not embed the historical fonts. Decorative page PNG/SVG/PDF proofs retain the M4 raster/outline extraction limits. Audio URLs are metadata; M5 does not record or play audio.

Existing document limits remain: 8 MiB state, 128 frames, 200,000 source scalars, and bounded undo history. Language data additionally caps 256 retained revisions, 10,000 content objects and 2,000 records per collection. Exceeding limits fails the transaction. Large-library performance, workspace-wide corpus indexing, automated revision merging and installer hardening belong to M6 or later revisions.
