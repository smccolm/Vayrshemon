Application **0.14.3** makes alignment automatic for text edits in complete four-column spreads, in both one-page and two-page view. When counts differ or the text needs more vertical space, the text edit is retained, previous spacing is restored and the status bar explains the pause; alignment resumes on a subsequent fitting edit. The small **×** at the edge of the source editor header hides the text-editing pane and returns focus to the page preview. ## Use it

Run `setup.bat`, then `launch.bat`. In Language Forge, open the language project and select **Gloss**.

1. Choose an annotated page test. **Preview gloss** shows its construction text and a word table. Select a word for its dictionary sense, compound explanation, grammatical analyses, discourse context, exact source spans and English adaptation notes.
2. In the working draft, **Load glossary** loads saved labels or proposes labels from the dictionary. Edit **Compact label**, **Inherent tags** and **Explanation**. Save to the draft, then commit in Versions. Invalid or stale edits remain available for correction and block navigation that would discard them. Historical versions are read-only.
3. Open the matching two-page reading book, whose third column is still empty. **Create four-column copy** creates and opens a separate native book, with two PNG proofs, a detailed gloss report and diagnostics. It rejects different source text, different English, a nonempty third column or an unfrozen language version.

The current local demonstration is `.local/demos/m13-gloss/`: `Vayrshemon.vayforge` contains the complete prior project history and experimental language **0.7.0** on branch `construction-gloss-0.7`. `final-spread/Construction-spread.vay.json` contains the current four-paragraph Tempest example and its editorial coda. The original M12 project and book are preserved. The version adds compact labels and a wiki page; dictionary records, grammar, natural-variation choices, test text and Maxima remain unchanged.

## Reading conventions

Words are separated by **·**; compact grammatical features follow in parentheses. For example, the requested construction can be written `Many · I(sg.) · be(prs.). One · we(sg.) · be(prs.).` This illustrates the notation; it does not replace the current example or assert an additional language rule.

| Label | Meaning |
| --- | --- |
| sg. / du. / pl. | Singular / dual / plural |
| prs. / pst. / fut. | Present / past / future |
| pst.d. / pst.i. / fut.d. / fut.i. | Distant / immediate past or future |
| simp. / prog. / perf. | Simple / progressive / perfect aspect |
| nom. / acc. | Nominative / accusative |
| cnt. | Count-noun modifier |
| th. | Thing class |
| n. | Verb-to-noun conversion |

The legend appears in Forge instead of taking space on the reading page. Simple aspect can be explicitly shown or omitted through the versioned glossary option. No absent feature is invented. Source-attested `we(singular)` remains `we(sg.)`; a collective interpretation is still a proposal. Compact compound labels refer to the selected dictionary sense and etymology; internal morpheme boundaries are **not** inferred from apostrophes or surface similarity. Full explanations remain in Forge.

## Formatting and preservation

The approved 865.498700 × 1120.057141 pt geometry, margins, black paper, 50 pt three-layer Thimfora and 22 pt Roman reading remain. The new gloss uses **22 pt transliteration 7 with exact 38 pt leading**, 24 pt paragraph-after spacing and the existing Roman bevel/glow. Explicit punctuation glyphs use Times New Roman with the same paint, because the archival font's slots do not consistently represent modern Unicode punctuation.

The copy validates unchanged page geometry and the other three frame contents. At 144 DPI it compares the entire left page and the right page's English half against the source, pixel for pixel. Paragraph starts align with the English where space permits; longer gloss paragraphs flow later without shrinking text or moving the protected columns. Measured delays are recorded. Overflow or missing glyphs stop creation with an actionable error. Existing conservative script collision warnings remain visible; they are not erased to manufacture a clean report.

Each paragraph has a native corpus record and linked source/gloss ranges. Saving and reopening preserves those links. Later text edits mark them stale; Undo restores them. Refresh a gloss by creating a new reviewed copy from the matching source and frozen version. A generated copy never silently rewrites the original.
