# M10 — variation in context

Software/API **0.11.0**. Language demonstration **0.4.0**, experimental. Native document **0.5.0**, paint engine **1.1.0**, variation definition **1.0.0**. Forge envelopes become **1.2.0** when variation is saved; 1.0.0 and 1.1.0 remain readable. Earlier executables reject the newer envelope instead of silently dropping context definitions. Merge and release operations never downgrade an envelope.

The repeated word openings in the M9 proof came largely from placing the full thing-class prefix on nearly every nominal, including repeated references and each item of an enumeration. M10 adds explicit, optional surface alternatives and evidence to review their use. It does not randomly respell words, manufacture synonyms, infer discourse, or enforce a diversity quota.

## Forge workflow

Open **Language Forge → Variation**. Select a page and **Inspect page**, or choose two frozen versions and **Compare repetition**. The comparison uses the after version's watch definitions on both texts. Counts include prefix concentration, clause openings, consecutive marked tokens, exact repeated words, lexical identities, context distribution and scalar locations. These are sample observations, not population frequencies or a naturalness score. Deliberate parallelism and rhetorical repetition can be appropriate.

**Definitions** edits versioned JSON proposals. Each alternative references a grammar record and a finite form rule, replaces an exact paradigm prefix, and declares its allowed context. It never rewrites a root substring or chains through another alternative. Complete original forms remain available. **Forms in context** shows available and blocked forms for a stable dictionary ID, feature bundle and context. **Freeze audit** writes reproducible evidence for a committed version. Save edits, then use **Commit version** to freeze them.

Laboratory cases and tokens can carry optional context objects. Available dimensions are register (citation/formal/literary/conversational), givenness (new/established), focus (neutral/contrast), coordination (independent/first/continuation) and role. Token context overrides case context; an annotated token's actual role is authoritative. Missing required context rejects a conditional form. Context annotations are editorial claims: the compiler cannot establish that an entity really is given or that adjacent nouns belong to a coordinated list.

Invalid or stale edits stay visible. Generation, project identity, document revision and idempotency guards remain in place. Historical views are read only. Definitions, case context, dictionary, wiki, merges and releases travel together in the Forge history export. Workbench documents retain their native language snapshot; complete test/variation history lives in the separate Forge project and frozen run evidence.

## Proposed language revision

The private demo branches from the retained M9 language 0.3.0. It preserves the dictionary and historical frequency evidence, all original tests, English text and formal paradigm. The new wiki explicitly proposes optional omission of the outer thing-class marker in literary register:

- An established, noncontrast subject or object.
- A noncontrast nominal predicate.
- A continuing subject in a same-class enumeration; the first item keeps full marking.

Case endings and the inner **ef’ event nominalizer remain**. Full forms remain available even when a short form is licensed. Formal/citation contexts and contrast block the new alternatives. These are newly proposed constructions, not recovered historical facts. The Shakespeare reading keeps full forms for foregrounded images and uses shorter forms for shared participants and continuing lists. It still has the M8 adaptation's documented losses of metre, ambiguity and literal equivalence.

The demo generator is `tools.m10_demo`; it consumes the ignored M9 history into a new private project, edits definitions/wiki through real Forge controls, commits the revision, runs the old frozen suite for regressions, runs the expanded suite, compares repetition, creates an experimental release and renders the approved page. It checks that the M9 database and original open Workbench state remain unchanged. No private font, source text, generated project or proof enters Git.

## Controls and evidence

Six operations bring the shared desktop/Python/CLI/MCP surface to **133**:

| Operation | Purpose |
| --- | --- |
| `forge.variation.read` | Read draft or frozen definitions |
| `forge.variation.replace` | Validate and save a guarded draft |
| `forge.variation.forms` | Inspect full and conditional forms |
| `forge.variation.audit` | Inspect the selected page |
| `forge.variation.run` | Freeze an audit and its input hashes |
| `forge.variation.compare` | Compare two pages using identical watch definitions |

`ui.forge` supports `section="Variation"`, `variation_test`, `variation_before`, `variation_after` and `variation_run`. Headless MCP uses `mcp --headless --variation`; live MCP discovers 0.11.0 automatically. `launch.bat --m9` retains the prior interface. Contracts are in `schemas/variation-command.schema.json` and `data/variation-*.json`.

Workbench test runs pin the language suite and variation report by hash. Named releases recompute both reports and verify the corresponding files; an experimental release keeps outstanding linguistic review visible. Snapshots without variation retain the original lab engine 1.0.0 result semantics; context-aware snapshots report engine 1.1.0. Repetition audit engine is 1.0.0. Bounds include 64 alternatives, 32 watches, 100,000 compiled form analyses, 10,000 audited tokens and 8 MiB report limits; displayed locations truncate after 256 per watch with an explicit flag.

## Presentation and setup

The approved enlarged portrait page remains 865.498700 × 1120.057141 pt, two independent full-height columns, black background, pale English, 50 pt script / 18 pt English and the original leading, margins and three-font paint. New prose reflows naturally and paragraph pairs are aligned by measured baselines; the content-independent presentation signature must be identical. The original approved document is separately rendered and compared against its protected geometry and pixels. No golden reference is replaced.

Fit Height, Fit Width, centered single-page views and Hand/Select remain. The demo presses the real PNG button, supplies a destination through the chooser, waits for the actual export worker, decodes the timestamped PNG and records its hash. The approved page uses the highest supported DPI below the requested value (292 for a 300 DPI request).

`setup.bat` and `tools/setup.ps1` install the pinned `requirements-m10.txt` chain, audit dependencies, run evidence checks and discover all public tests. No new dependency is needed. Each run retains its own log. Public synthetic regression strings are structural fixtures, never invented language examples.

## Next linguistic work

Broaden the corpus with coherent dialogue, narration and ceremonial prose. Record speaker/register, information structure, collocations and competing readings with provenance. Compare lexical and syntactic options across genres before assigning preferences or probabilities. Introduce polysemy, productive word formation and lexical alternatives through independent versioned proposals. Human acceptance remains separate from mechanical assertions; free-prose parsing and semantic equivalence are not implemented.
