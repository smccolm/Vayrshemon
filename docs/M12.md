## Read the actual Roman forms

The user selected the original **transliteration 7.ttf** after its font/chart inspection. Its Roman outlines include marked vowels and digraphs at the corresponding legacy character positions. For example, the stored `ß` slot displays ō and `Ñ` displays ch. Ordinary Times New Roman would display those literal stored characters instead. Both readings are available, with the original custom font selected by default.

**Language Forge → Reading** provides a page selector and three modes:

| Mode | Right column |
| --- | --- |
| English translation | The versioned English text and approved English typography |
| Transliteration 7 · intended Roman forms | Identical script slots, painted by the original Roman font |
| Times New Roman · literal slots | Identical script slots, painted by the installed Times New Roman font |

Select **Preview reading** to inspect both alphabets, then **Run in Workbench** to create a separate saved test page from a committed language version. **Enable profile** adds the supported, hash-identified reading policy to a guarded working draft. Text, policy, dictionary, wiki and tests are frozen together when that draft is committed. The English text remains in the language test when another reading is displayed.

In the Workbench, **Reading copy → Create reading copy** also makes a separate editable document from the current one-page, two-column Thimfora 79 book. It captures the current left-column text, preserves all slots and case, resolves the exact Roman font and measures paragraph-start alignment. The original document is unchanged; normal save prompts still protect unsaved work when switching documents. Columns remain independently editable. Create a fresh copy or rerun the frozen test after changes; this is not live linked text.

This is a **font reading**, not a guessed phonemic transcription, IPA conversion or Unicode respelling. Copying plain text returns the original legacy characters. PNG/SVG proofs preserve the visible Roman glyphs. No Unicode uppercasing or normalization is applied. All 47 actual Maxima/Minima pairs have corresponding distinct Roman forms. The fonts' provenance and known punctuation differences are recorded in [font-reading research](research/m12-font-reading.json).

## Preserve the approved page

Reading mode deliberately changes only the right-column font in the presentation contract. It retains the enlarged **865.498700 × 1120.057141 pt** page, full-height frames, margins, black paper, pale right column, **50 pt script / 18 pt Roman**, original leading and paragraph spacing, and the exact Thimfora **79/81/80** origins, bevels, shading and glow. Paragraph starts are realigned from measured baselines as they are for English. The separate approved baseline is still checked against its original protected state, geometry and RGBA hashes; none is replaced.

The original Roman font's lowercase `p` has a small negative left sidebearing. In the Tempest reading it extends **0.046875 pt** left of the right frame. The glyph remains visible. `FRAME_OVERFLOW` remains recorded; a narrowly bounded, hash/glyph-identified sidebearing check classifies this as **Needs review** only when all text advances and vertical bounds fit. Other overflows still fail. This preserves both the font and honest troubleshooting output.

## Develop variation without erasing the fuller reading

Language **0.6.0** retains M11's Tempest source, English, eight sentence-initial Maxima, dictionary and all 256 earlier assertions exactly. Its new continuity proposal has separate grammar, wiki, assertion and page IDs. Two coherent readings compare:

> Our actors are spirits. They have become only breath.

The full version repeats the actors expression; the optional literary continuation leaves that established subject implicit. Predicate, adverb scope and finite tense remain. This option requires an explicit immediately preceding subject with the same author-annotated lexical identity, established discourse status, subject topic, neutral focus and literary register. Topic shifts, contrast, missing context, absent reference, a different identity and an invalid antecedent clause reject it. Full forms and prior orders remain available.

The compiler checks the annotated identity and the antecedent's own assertions. Bound pages additionally require that antecedent immediately before the continuation in the same paragraph. It cannot infer real-world reference, rhetorical quality or semantic equivalence. The proposal is recorded as **draft**, not attested language or a mandate to omit repeated subjects. The wiki explains these limits and retains the fuller construction for comparison.

## Demonstration and controls

`python -m tools.m12_demo --directory <new-private-directory>` restores the M11 history into a new project, creates a branch, previews Roman readings, edits the wiki through the Forge, commits 0.6.0, checks old-case regressions and runs the expanded suite. It renders English Tempest, full and implicit continuity readings, and the final parallel Roman Tempest on the approved page. It freezes **0.6.0-experimental.1**, saves an editable reading copy, presses the real PNG button with its timestamped filename and decodes the export. Source projects and the approved baseline remain separate. Use `--open-existing --serve` to reopen a completed demonstration with recovery and live controls.

Four operations bring the shared API/CLI/MCP surface to **144**:

| Operation | Purpose |
| --- | --- |
| `forge.reading.read` | Read the version's policy and available modes |
| `forge.reading.enable` | Add the supported profile to a guarded draft |
| `forge.reading.inspect` | Inspect exact text, hashes and Maxima/Minima counts |
| `page.reading.copy` | Create an independent native reading document and proof |

`forge.test.run` accepts `reading_mode`; its API default remains `translation` for existing clients. The Reading GUI defaults to `transliteration`. `ui.forge` supports `section="Reading"`, `reading_test`, `reading_mode` and `reading_preview`. Headless controls use `mcp --headless --reading`; live MCP recognizes 0.13.0. `launch.bat --m11` retains the preceding interface. Published contracts are `schemas/reading-command.schema.json` and `data/reading-*.json`.

Reading evidence is hashed into page runs and recomputed during release creation. Forge history, differences and merges preserve the policy, with monotonic envelope upgrades so older executables cannot silently drop it. The Laboratory case editor exposes antecedent JSON. Maxima application remaps antecedent case IDs when it clones a bound page; earlier cases remain unchanged.

`setup.bat`, PowerShell setup, dependency auditing, release verification and CI use the pinned `requirements-m12.txt` chain. **No new dependency.** Full setup passed **208 tests**, including the standard parallel-translation fixture, approved visual baseline and save/reopen/export checks. The expanded language suite has **271 cases: 269 Pass, 1 Needs review, 1 Unsupported**, with no regressions in the earlier 256 cases. Eight sentence initials retain Maxima; no glyphs are missing in the demonstrated readings. The English Tempest proof is pixel-identical to M11; the parallel Roman proof retains identical left-column pixels. The actual PNG button exported a **3511 × 4543** image at **292 DPI**. Final evidence and private artifact hashes are in [M12 validation](research/m12-validation.json). Original fonts, projects, source passages, rendered proofs and logs remain ignored.
