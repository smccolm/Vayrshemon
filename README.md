## Repeatable research

On Windows, double-click [`setup.bat`](setup.bat), then [`launch.bat`](launch.bat). Setup reuses the existing `.venv`. When creating an environment, it finds Python 3.12 (64-bit) through the registry, known locations, PATH or the Python launcher; if missing, it downloads and verifies the official Python 3.12.10 x64 installer and installs it for the current user. It then creates `.venv`, installs the pinned M0–M14 Python dependencies, audits notices, and runs all public checks. M14 also builds the native Explorer component with MSVC C++ and the Windows SDK; setup installs the Microsoft build tools through winget if absent. Windows administrator approval installs that component under `C:\Program Files\VayrshemonShell`; file associations remain per-user. An unchanged component needs no further elevation. The current environment remains Python 3.12.7 with Qt 6.8.3. Setup also creates a `Vayrshemon` desktop shortcut pointing to `launch.bat`, using the centered Memon icon. Logs remain in `.local/logs/`; use `setup.bat --no-pause` for automation. No manual Python, Rust or Node installation is needed. The Python bootstrap leaves PATH, file associations and existing Python installations alone; it refuses to overwrite an unusable existing Python312 folder. All milestone dependency files live in [requirements/](requirements/); setup installs `requirements/requirements-m14.txt` and verifies the four bundled application fonts by SHA-256. These fonts are registered privately by the application, without installing them into Windows.

Normal launches close the command window immediately. Troubleshooting output is saved in `.local/logs/launch-*.log`; a failure dialog points to its log. To deliberately keep a visible console, run `.venv\Scripts\python.exe -u -m vayrshemon editor` from a terminal.

The bottom bar reads **zoom → one/two-page icons → < → Page [number] of total → >**. Enter a number from 1 through the last page to jump within the open file. Paired arrows turn whole spreads; entering a right page retains its exact number until the next turn. Fit Height/Fit Width or manual zoom follows navigation. Page turns preserve document formatting, Maxima and Undo history.

M14 0.15.31 supports complete books in one `.vay` (up to 32,768 pages, 65,536 frames and 32 million text scalars). Compressed native storage is bounded at 1,536 MiB expanded, 256 MiB compressed and 384 MiB for the wrapper. The complete KJV uses 20,498 pages; opening a document this large can take several minutes. Frame editors load on demand. The ordered-volume utility `python -m tools.combine_volumes INDEX OUTPUT --title TITLE` retains every page and typesetting record, checks source hashes, and writes a new book with a saved preview and verified font-complete backup. Source volumes remain intact. Large books require this release or later; old documents still open normally.

Use **Language → Update transliteration** to refresh the Roman column from Vayrshemon in the current page or spread. It works in both page views, preserves formatting and Maxima, and undoes in one step. The app explains replacement of direct Roman edits before applying it. Reading-copy controls no longer occupy the ribbon.

M14 opens maximized with a blank document in single-page mode and Fit Height, even if the previous session used two-page mode. File → New also selects one-page mode. Saved `.vay` documents restore their saved one/two-page view. Panel preferences are remembered; new workspaces match the approved first-run view: controls collapsed and unpinned, source editor/diagnostics/guides hidden, Select active, Fit Height, Monochrome: black on white and single-page mode selected. File → New also starts black on white; existing documents retain their saved color mode. New documents automatically gain Unta numbers when they contain multiple pages, at 50 pt with a preferred 28 pt edge inset. View → Page numbering controls these defaults per document, including the multipage-only rule. Saved numbering choices remain intact. Toggle each under View. File → Recent documents reopens your save. M14 loads the bundled Thimfora 79/80/81 and Transliteration 7 fonts without requiring Inputs. Apply relief in Paint; import the verified language archive in Language. Select clicks a frame to edit; Hand drags the page. The left edge arrow expands/collapses controls; Pin keeps them open. Ctrl+Alt+B toggles the panel and Ctrl+Alt+P toggles pinning. Additional fonts and language records can still be imported. Save documents as `*.vay`. Save for a new document, Save As and Open start in `Saves/` (`E:\Vayrshemon\Saves` here); ordinary Save updates an existing file in place. Setup creates `Saves/`, which is excluded from Git. Recovery, history and verified font-complete backups live in `.local/`. Save As suggests the new extension for old files. M1–M4 imports require a new path; M5–M13 files preserve their editable state and gain the new wrapper when saved. Older app releases cannot read the new wrapper; retain the original or its backup for rollback. `launch.bat --m13`, `--m12`, `--m11`, `--m10`, `--m9`, `--m8`, `--m7`, `--m6`, `--m5`, `--m4`, `--m3`, `--m2` and `python -m vayrshemon lab` retain earlier interfaces. PNG stays in the bottom bar; SVG and PDF are under File → Export. The PNG button and all menu export options start in `Exports/` (`E:\Vayrshemon\Exports` here), which setup and export dialogs create as needed and Git ignores. PNG and SVG export one date/time-named file in single-page view, or a matching _Left / _Right pair with one timestamp and snapshot in two-page view, using cancellable background jobs. PDF exports all separate numbered pages to one `DateTimestamp.pdf`, opening in single-page or facing-page view to match the app. Reader settings can override this opening preference. PDF export shows a progress bar, page count, elapsed time and Cancel in the reading status bar with panels collapsed. Monochrome books and color books with a decorated first page compose each page once. Bounded reuse of exact glyph outlines speeds color preview and export without changing DPI, bevel/glow or Maxima; finalization and verification remain visible until publication.

File → Close (`Ctrl+W`) closes the document and leaves the app open on a clean Untitled page, centered in Fit Height and single-page mode. File → New uses the same initial fit. Changes since the last save/open offer Save, Discard or Cancel. Cancelling or failing a save keeps your document open; unchanged files close immediately.

Setup also writes `.local/mcp-config.json` for an MCP client. It discovers the active editor/lab and connects through a current-user-only local socket; mutations require the document ID, current revision, and an idempotency key. The same interface is available as `.venv\Scripts\python -m vayrshemon call session.status`. See the [M6 guide](docs/M6.md) for headless operation and the [published tool schemas](data/file-mcp-tools.json).
